# Phase 10 — collision test on ares

This is a **test scene only**, not the original Corn Kidz 64 levels, models or
`PlayerCtrl` physics.

## Changes
- One temporary solid blue pillar at (3, 0, 4) (width 1.4, height 2.0).
- Expanded AABB collision against the yellow avatar's 0.76-wide footprint.
- Axis-separated movement resolution for simple wall sliding at 30 Hz.
- Blue pillar flashes orange on collision; footer reports collision step count
  `H` and player X/Z/Y.
- **START:** toggle solid collision ON/OFF; turning it on from inside the pillar
  ejects the player to the closest free face. **B:** reset state and re-enable collision.
- Original Phase 9 near-plane clipping remains unchanged.

## Controller test script
1. Load `ck64_diag_phase10_collision.z64` in ares and find the blue pillar.
2. Move the yellow box toward it. It should stop against a side, briefly
   flash orange, and the H counter should increase while pushing.
3. Move diagonally along the side to verify sliding.
4. Press START (COLL:OFF); you should be able to move through it.
5. While inside, press START again: the yellow box should be pushed outside.
6. Press A to jump near the pillar, B to reset, C-left/right to orbit, Z to
   access the old diagnostic view.
7. Record video and report unexpected clipping, shaking, tunneling or stalls.

## Verification boundaries
The four new C11 test groups cover front/back impact, diagonal sliding,
re-enabling collisions while overlapping, jump-height overlap and reset state.
This demo implements *no* physics extracted from the commercial game's
Unity assembly, and it is not a playable reconstruction.

Native build output is generated by the GitHub Action on a toolchain
runner and published in `roms/` only after compilation succeeds.
A successful build alone is not ares runtime validation.
